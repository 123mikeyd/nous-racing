# Nous Racing

A starting point for a Nous community racing game.

The starting animation set is:

- **Entering Car**
- **Exiting Car**
- **Driving**
- **Honking Horn**

This repository is a handoff brief, not a playable game. These are character animations; vehicle controls, car physics, horn audio, and game integration are still for contributors to build.

## Get the animations

1. Sign in to [Mixamo](https://www.mixamo.com/) with your own Adobe account.
2. Choose or upload your character, then search for each animation name listed above.
3. Download the clips as FBX for your character. Keep the same character/rig across the four downloads.
4. Import the FBXs into Blender or your chosen game engine to begin building.

The raw Mixamo files are not included. Adobe's [Mixamo licensing FAQ](https://community.adobe.com/questions-696/mixamo-faq-licensing-royalties-ownership-eula-and-tos-589400) permits use in creative projects, but excludes public redistribution of the raw character and animation files. Obtain the clips directly from Mixamo under its terms.
